# CSV TUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Rust ratatui app that loads a CSV file into an in-memory rusqlite table and lets users run readonly SQL queries from a bottom SQL pane.

**Architecture:** A small binary crate split into focused modules: CSV import (`csv_loader`), query execution and readonly validation (`db`), application state/event mutation (`app`), and ratatui rendering (`ui`). CSV cells are stored as TEXT in a single `csv_data` table with generated spreadsheet-like column names (`a`..`z`, `aa`...).

**Tech Stack:** Rust 2024, ratatui/crossterm, rusqlite bundled SQLite, csv, anyhow, clap.

---

## Files
- Create `Cargo.toml`: package and dependencies.
- Create `src/lib.rs`: module exports for tests.
- Create `src/columns.rs`: generated column names.
- Create `src/csv_loader.rs`: CSV import into SQLite memory DB.
- Create `src/db.rs`: readonly SQL validation and query materialization.
- Create `src/app.rs`: TUI state transitions.
- Create `src/ui.rs`: ratatui layout and widgets.
- Create `src/main.rs`: CLI, terminal setup, event loop.
- Create `tests/integration.rs`: behavior tests.
